# ClearModel

ClearModel is a research paper understanding platform designed to help users understand academic papers through structured explanations, mental models, and methodology breakdowns.

## Tech Stack

Frontend:
- Next.js
- React
- Tailwind CSS

Backend:
- FastAPI

## Current Status

Early MVP under development.

Current features:
- Landing page
- PDF upload page
- FastAPI backend integration
- Structured result rendering

Planned features:
- Workspace page
- Mental model diagrams
- Method decoder
- Assumptions and limitations analysis
